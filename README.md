# 생각이 만나는 미술관 · 팝 디자인 / 공통 9단계

## GitHub Pages에 올리기
1. 이 ZIP 파일의 압축을 풉니다.
2. index.html, app.js, lessons.js, clean9.css, pop.css, .nojekyll을 저장소의 최상위 경로에 함께 올립니다.
3. GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다.
4. 배포가 끝나면 Pages 주소로 접속합니다.

기존 파일을 바꿀 때에는 같은 이름의 파일을 모두 교체하세요. 화면이 이전 모습이면 Ctrl+Shift+R로 새로고침하세요.

## 포함 기능
- 시각적 연결 / 감정의 표현 / 공감각 하모니
- 각 영역에 공통 9단계, 활동별 질문과 실천 안내
- 그림과 픽셀 표현, 8칸 소리 실험
- 기록 자동 저장, JSON 저장·불러오기, 그림 PNG 저장, 인쇄
- 교사와 함께 별도 ChatGPT 창에서 사용하는 AI 질문 도우미

별도 설치나 API 키가 필요하지 않습니다. 학생 기록은 현재 브라우저에 저장됩니다. AI 응답 자동 생성 및 학급 공동 저장 기능은 없습니다.
